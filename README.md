# A/B Test Data Analysis

A/B test for an e-commerce website to see whether a new landing page leads to a higher conversion rate than the old one.

This project was completed to learn and practice probability, hypothesis testing, and regression. After checking and cleaning the data, I compare conversion rates using simulation, a two-proportion z-test, and logistic regression. I also examine whether country and its interaction with the landing page affect the results.

The analysis did not find sufficient evidence that the new page improves conversion. The notebook explains the steps and how I interpreted the results.

To run the notebook, keep `ab_data.csv` and `countries.csv` in the same folder.

The datasets were provided by Udacity as part of their Data Analysis Advanced Track.
